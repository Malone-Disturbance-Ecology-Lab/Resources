# Resources

Reusable analysis scripts and utilities for the Malone Disturbance Ecology Lab.

## Contents

- **`clock_drift_alignment/`** — Align eddy-covariance flux data with met/biomet
  data when the two streams are logged on separate instruments whose clocks
  drift apart, including the case where the drift rate varies with temperature.
  See [`clock_drift_alignment/README.md`](clock_drift_alignment/README.md).
